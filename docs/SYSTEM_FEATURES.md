# Youlai Admin 系统功能说明

本文档以当前仓库代码为准，说明 PC 管理端、移动端和 FastAPI 后端已经提供的业务能力、使用边界及主要入口。

## 1. 系统组成

| 端        | 入口      | 主要职责                           |
| --------- | --------- | ---------------------------------- |
| PC 管理端 | `web/`    | 管理后台、系统配置、流程和数据维护 |
| 移动端    | `app/`    | H5、微信小程序及 App 端移动工作台  |
| API 服务  | `server/` | 认证、权限、业务数据和文件服务     |

PC 端通过 `/dev-api` 或 `/prod-api` 代理访问后端 API；开发环境默认指向 `http://127.0.0.1:8000`。

## 2. 认证与账号

### 登录

- 用户名密码登录。
- 图片验证码校验。
- JWT Access Token / Refresh Token 会话机制。
- Token 刷新、退出登录和多端登录开关。
- 登录成功写入登录日志，个人中心展示当前用户最近 3 次成功登录记录。
- 二维码登录相关 API 已提供；短信登录和短信验证码在未接入短信服务时返回未接入提示。

### 个人中心

- 查看用户名、昵称、性别、部门、角色、创建时间和账号安全状态。
- 编辑昵称和性别。
- 修改密码；修改成功后当前会话失效并要求重新登录。
- 上传和更新头像，支持图片类型校验与 5 MB 大小限制。
- 查看和刷新近期登录记录。
- 手机号、邮箱绑定/更换/解绑入口；短信或邮件验证码服务未配置时不会伪造成功。

## 3. 权限体系

- 动态菜单和动态路由：登录后根据用户权限加载可访问菜单。
- 角色权限：角色可分配菜单和按钮权限。
- 按钮权限：页面按钮通过权限标识控制显示和可用状态。
- 数据权限：后端按角色数据范围过滤业务数据。
- 多租户开关：PC 端通过 `VITE_APP_TENANT_ENABLED` 控制租户相关界面，后端保留租户配置能力。

## 4. PC 管理端功能

### 工作台

- 仪表盘统计和访问趋势。
- 在线用户、访问概览等运营信息（数据取决于后端日志）。
- 顶部全局菜单搜索，支持历史记录、键盘导航和 `Ctrl/Cmd + K` 快捷键。
- 多布局、主题切换、暗色模式、语言切换、全屏和通知中心。

### 系统管理

| 模块     | 功能                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 用户管理 | 用户增删改查、状态切换、角色分配、部门筛选、批量操作、导入导出、重置密码 |
| 角色管理 | 角色维护、状态管理、菜单权限和数据权限分配                               |
| 菜单管理 | 菜单、目录、按钮和外链配置，排序及显示状态管理                           |
| 部门管理 | 部门树维护、排序和状态管理                                               |
| 字典管理 | 字典类型及字典项维护、状态管理                                           |
| 参数配置 | 系统配置项查询、编辑和刷新缓存                                           |
| 通知公告 | 公告发布、编辑、撤回、删除和用户阅读状态                                 |
| 操作日志 | 日志查询、状态筛选、时间筛选、详情查看和历史清理（需管理员权限）         |
| 应用管理 | 应用信息、状态及应用配置维护                                             |
| 租户管理 | 租户、租户套餐和租户状态维护（启用多租户时使用）                         |

### 工作流

- 流程模型列表和流程模型配置。
- BPMN 流程设计器和流程预览。
- 流程发起。
- 待办任务、我的任务和已办任务分组查看。
- 审批处理、流程节点、审批意见和流程实例详情。

### 动态表单

- 表单定义创建、编辑、复制和发布。
- 可视化表单设计器和预览。
- 表单数据列表、筛选和详情查看。
- 发布入口配置、访问方式配置和公开分享页 `/f/:formKey`。

### 代码生成

- 数据库表列表和表结构读取。
- 基础配置、字段配置和页面类型配置。
- 页面类型支持「普通」（单文件 Element Plus 页面）与「封装(CURD)」（`PageSearch`/`PageContent`/`PageModal` + `config/*.ts`）。
- 代码预览与文件类型/范围筛选。
- TypeScript 前端页面/API 及 FastAPI 后端模板生成；后端复用 `app.database` 的 `BaseIdMixin`、`TimestampMixin`、`SoftDeleteMixin`。
- 配置了上级菜单时额外生成 `server/sql/<表名>_menu.sql` 菜单初始化脚本（只生成文件，不自动写库）。
- 生成文件下载 ZIP 或写入本地（取决于当前运行环境权限）。

生成的代码不会自动接入工程：后端需按模块 `__init__.py` 中的说明在 `registry.py` / `main.py` 注册，
前端页面需执行菜单 SQL 并在「角色管理」中分配权限后才会出现在侧边栏。

### 示例与基础组件

`web/src/views/demo` 提供表格、表单、拖拽、上传、图标、路由和组件使用示例，用于开发参考，不属于核心业务菜单。

## 5. 移动端功能

移动端位于 `app/`，使用 uni-app 页面和分包机制，当前包含：

- 登录和用户会话。
- 首页/工作台。
- 我的页面、个人资料和账号相关入口。
- 移动端用户、角色、菜单、部门、字典、通知和系统配置页面。
- 监控、操作日志和图表展示。
- H5、微信小程序、App 及其他 uni-app 平台构建脚本。

具体平台能力受 `manifest.json`、平台 SDK 和构建环境影响。

## 6. 后端服务能力

后端路由按业务模块组织：

- `app/auth`：登录、登出、刷新令牌、验证码和二维码登录。
- `app/system/user`：用户、个人中心、密码、绑定信息和登录记录。
- `app/system/role`：角色和权限分配。
- `app/system/menu`：菜单和按钮权限。
- `app/system/dept`：部门树。
- `app/system/dict`：字典类型和字典项。
- `app/system/config`：系统参数。
- `app/system/notice`：通知公告。
- `app/system/log`：操作日志和访问统计。
- `app/tool/file`：本地或 S3/RustFS 文件上传。
- `app/tool/codegen`：代码生成。
- `app/tool/sse`：服务端事件推送。
- `app/tool/wxma`：微信小程序相关接口。
- `app/captcha`：图片验证码。

统一 API 响应、异常处理、分页、CORS、限流和 JWT 依赖由 `app/response.py`、`app/exceptions.py`、`app/pagination.py`、`app/middleware.py` 等基础模块提供。

## 7. 数据与外部服务边界

- PostgreSQL：业务数据、用户权限、流程和日志。
- Redis：会话、缓存、限流及相关临时状态。
- S3/RustFS：文件对象存储，可按配置切换。
- 邮件、短信：绑定和验证码能力需要配置真实服务；未接入时接口会明确返回 501，不产生虚假成功结果。
- 操作日志：由后端装饰器记录请求、用户、设备、浏览器、系统和执行状态。

## 8. 运行与验证

```bash
# PC 管理端
cd web && pnpm dev

# 移动端 H5
cd app && pnpm dev:h5

# 后端
cd server && python -m uvicorn app.main:app --reload
```

建议提交前执行：

```bash
cd web && pnpm type-check && pnpm build
cd ../app && pnpm type-check
cd ../server && pytest && ruff check .
```

## 9. 安全要求

- 不要提交 `server/.env`、数据库密码、Redis 密码、JWT 密钥、S3 密钥或邮件密码。
- 使用 `server/.env.example` 创建本地配置，并为 `JWT_SECRET_KEY` 生成至少 32 字符的随机值。
- 前端环境变量会进入公开构建产物，只能存放公开 URL、端口和功能开关。
- 生产环境请替换 Docker Compose 中的示例密钥，并限制 CORS 来源。
